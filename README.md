# 💌 Daily Tasks — A Quiet Room for Two

A minimal, ultra-private shared workspace built for two people to manage daily tasks, messaging, and shared moments.

![Daily Tasks Logo](frontend/public/app-logo.png)

## ✨ Features

- 🔐 **2-Seat Room Pairing**: Connect via QR Code, 6-digit Invite Code, or 1-Tap Link.
- 📝 **Daily To-Do List**: Shared task management with due dates and real-time status updates.
- 💬 **Private Messaging**: Real-time synchronized chat room with push notifications.
- 🔒 **Passcode PIN & Auto-Lock**: Passcode security with customizable inactivity auto-lock.
- 🔑 **Password Recovery**: Secure email-based password reset.
- 📱 **Installable PWA**: Mobile home screen app support for iOS & Android.

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons |
| **Backend** | Node.js, Express, TypeScript |
| **Database** | MySQL, Drizzle ORM |
| **Caching** | Upstash Redis |
| **Email** | Nodemailer (SMTP) |

## 🚀 Quick Setup

### 1. Clone & Install
```bash
git clone https://github.com/your-username/daily-tasks.git
cd daily-tasks
npm install
```

### 2. Configure Environment
Copy `backend/.env.example` to `backend/.env` and fill in your variables.

### 3. Run Application
```bash
npm run dev
```
